# Change Log

All notable changes to the "vs-code-keybindings-for-pybricks" extension will be documented in this file.

## [Updates]

- 1.1.1 Updated so it will add sample text to the settings.json file if the entry isn't already there

- 1.1.0 Added a status bar note in the VS Code window in response to moving from a setting for RobotName in the Windows environment to a user setting within VS Code. Clicking the status bar will open the user JSON settings file so the fllRobotName setting can be updated.
